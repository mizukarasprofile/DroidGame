Droid Battle Game

A Java-based turn-based strategy and combat simulation game built with Object-Oriented Programming (OOP) principles.

Project Overview
The game simulates battles between different types of customizable droids. Players can configure teams, select various droid classes with unique combat stats (health, damage, armor,criticalChance, special abilities like healing  ), and simulate 1v1 duels or team battles.

 Key OOP Concepts Implemented
- **Encapsulation:** Clean separation of droid attributes, health states, and combat behavior.
- **Inheritance & Polymorphism:** Base `Droid` class extended by specialized combat archetypes with distinct abilities and attack patterns.
- **Battle Mechanics:** Turn-based round simulator managing turn order, attack calculation, and victory conditions.

Tech Stack
- **Language:** Java (JDK 17+)
- **Architecture:** OOP / Console Application
